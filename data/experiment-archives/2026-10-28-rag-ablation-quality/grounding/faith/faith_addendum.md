How to read the evidence: each item's EVIDENCE is in its own file (path given in the item, relative to the faith directory). Some files are very large (over 1 million characters), so do not try to read them whole. For every claim, search the evidence file (Grep for the figure, name or key term, also trying the English equivalent and alternative number formats such as "7.4 billion" / "7,4" / "$7.4B"), then Read the surrounding lines before labelling. Mark a claim "unsupported" only after you have searched for it. Small files can be read in full.
