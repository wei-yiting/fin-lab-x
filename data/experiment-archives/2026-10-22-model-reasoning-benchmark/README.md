# Model × Reasoning Benchmark — 2×2 on the zh diagnostic set (30 rows × 3 runs)

> **One-line takeaway:** Raising reasoning strength made both GPT-5.6 Luna and Gemini 3.6
> Flash slower (+11.5 s / +17.1 s per run) with no detectable change in execution health.
> Gemini was faster at both tiers and used a third of the input tokens, but at the medium
> tier it still cost more per run. None of the 360 runs failed because of the model.

This directory archives the 2×2 model-family × reasoning-strength benchmark (DEV-206). It
is also the pre-revision baseline for the shared-prompt work, and it supersedes the
2026-10-21 dev-split round (tag `experiment/2026-10-21-agent-config-benchmark-dev`),
which ran before the edgartools fix.

## Files

| File | What it is |
|---|---|
| `report.md` | The reference report |
| `metrics.csv` | One row per (row, arm, repetition), 360 rows: health, per-tool calls, hard vs budget-blocked tool errors, TTFT/E2E, tokens incl. reasoning/cached, per-call-priced cost, long-context-priced calls, drift and citation checks |
| `tables.md` | The report's tables as generated by `analyze.py` |
| `summary.json` | Machine-readable arm summaries, paired contrasts, health by source |
| `config_dump/` | Every arm as actually resolved, plus the alignment check (only model settings differ: PASS) |
| `prewarm/` | Per-worker SEC pre-warm results (all 24 filers OK) |
| `braintrust_links.json` | One Braintrust experiment per (arm, repetition), for both the initial batch and the resume batch |
| `raw.tar.gz` | Full per-run records (response, tool calls with args and results, usage per model call, tool timings, order, timestamps). Extract with `tar xzf raw.tar.gz`, then point `analyze.py --raw-dir raw`. Live inputs can't be replayed and Braintrust free-tier traces expire after 14 days, so this is the permanent record |
