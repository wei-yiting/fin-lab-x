# Prompt × Tool 2×2 Ablation — separating the reader prompt from `sec_filing_search` (30 rows × 3 runs × 4 cells)

> **One-line takeaway:** Not skipping required 10-K evidence is a prompt effect (SEC-skip
> runs 10/69 → 2/69 without search, 7/69 → 0/69 with it; prompt main effect −0.11
> [−0.22, −0.02], sign test p = 0.06 on 5 discordant rows). Fewer SEC tokens and lower
> cost are a tool effect. The latency gain needs both. Process and routing metrics only;
> answer quality is not graded.

This directory archives the prompt × tool factorial (DEV-223, child of DEV-220). It
splits the [RAG bundle ablation](../2026-10-22-rag-bundle-ablation/)'s bundle into its two
factors. All four cells, including fresh re-runs of the bundle ablation's A and B, ran
in one window.
