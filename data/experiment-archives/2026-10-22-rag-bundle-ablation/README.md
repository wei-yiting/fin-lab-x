# RAG Capability-Bundle Ablation — chunk search vs whole-section 10-K reading (30 rows × 3 runs)

> **One-line takeaway:** With the model fixed, the RAG bundle (`sec_filing_search` + reader
> prompt) put 34k fewer SEC tokens into context per question, finished 12.4 s faster and
> cost 69% less, with no change in execution health. Answer quality is not yet known: the
> 30-pair blind review is pending.

This directory archives the RAG bundle ablation (DEV-220), testing ADR-0010's "RAG over
long-context reading" assumption. It supersedes the E1 half of the 2026-10-21 dev-split
round.
